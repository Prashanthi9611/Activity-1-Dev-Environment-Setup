# Activity 1 – C/C++ Development Environment Setup

1. Installed Visual Studio Code on macOS.
2. Installed the Microsoft C/C++ extension in VS Code.
3. Installed Homebrew to manage development tools.
4. Installed MinGW-w64 using the command `brew install mingw-w64`.
5. Initially faced the issue that the `brew` command was not recognized. Resolved it by adding Homebrew to the system PATH.
6. Verified the MinGW-w64 compiler using `x86_64-w64-mingw32-gcc --version`.
7. Created and successfully executed `hello.c`, displaying "Hello, World!" in the VS Code terminal.
